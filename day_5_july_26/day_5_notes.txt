Map
===
-Map is a collection that stores data in key-value format.
-Map Properties:
	Keys can be of any datatype
	Keys are unique
	Insertion Order is preserved
Why Do We need Map:
	When keys are not strings
	For Dynamic key-value data
	Faster 

// create a new Map Object with initial value
const userMap = new Map([['name', 'sanjay']]); // Entry 
console.log(userMap);

// Add/Update value
userMap.set('age', 50); // Add
userMap.set('address', 'Bangalore'); // Add
userMap.set('role', 'Admin'); // Add
userMap.set('role', 'Trainer'); // Update

// Check Map Size
console.log('Size: ', userMap.size);

// Print the Map
console.log(userMap);

// Read 1 value
console.log('Name: ', userMap.get('name')); // Sanjay

// Iterate Map
for (const [key, value] of userMap) {
   console.log(`${key} ==== ${value}`);
}

// Remove an Entry
userMap.delete('age');

// Remove all entries
userMap.clear();

 
 
 
 
Set
===
-A Set is a Javascript Object that stores unique values.
-Set can be iterated using loop,forEach()
-Set Properties:
	No Duplicate Values
	Maintains Insertion Order
	Can store any data type
	No indexing
-When To Use Set:
	Remove Duplicates easily
	Fast lookups (O(1))


// create a set object
const planets = new Set();

// add items to set object
planets.add('Mercury');
planets.add('Earth');
planets.add('Venus')
planets.add('Earth').add('Mars'); // Chainable Method

// To Print the complete set
console.log(planets); // { 'Mercury', 'Earth', 'Venus', 'Mars' }

// check the size of a set
console.log('Set Size:', planets.size);  // 4

// check an item exists in a set or not
console.log(planets.has('Earth')); // true

// Delete an item from a set
planets.delete('Earth'); // deletes 1 item

// After delete
console.log(planets); // { 'Mercury', 'Venus', 'Mars' }

// Delete All the items 
planets.clear();

console.log(planets); // {}



What is a Promise
=================
-A promise is an object that holds the future value of an asynchronous operation.
-A Promise object represents a value that is not available now, but will be resolved/available at some point in the future.
-Promise object can have different states:- pending, resolved/fulfilled, rejected.
ex:-if we request some data from a server, promise promises us to get that data that we can use in the future. 


ex: 
// fetch() returns a promise Object
let usersPromise= fetch('https://jsonplaceholder.typicode.com/users');
console.log(usersPromise);

methods of Promise class:
------------------------
Promise.all(promises) – waits for all promises to resolve and returns an array of their results. If any of the given promises rejects, it becomes the error of Promise.all, and all other results are ignored.
Promise.allSettled(promises) – when all of the given promises have either fulfilled or rejected
	status: "fulfilled" or "rejected"
	value (if fulfilled) or reason (if rejected).
Promise.race(promises) – waits for the first promise to settle, and its result/error becomes the outcome.
Promise.any(promises) – waits for the first promise to fulfill, and its result becomes the outcome. 
				If all of the given promises are rejected, AggregateError becomes the error of Promise.any.
Promise.resolve(value) – makes a resolved promise with the given value.
Promise.reject(error) – makes a rejected promise with the given error.



Async & Await
-------------
-async makes a function return a Promise,await makes a function wait for a Promise.
-Async functions enable the programmer to write promise-based code, Syntax and structure of code  appears like synchronous code but doesn’t block the main thread of execution.
-async and await makes the program very clean and understandable.there is no need of .then()
-we can declare the Async functions in JavaScript by specifying the “async” keyword in front of the function definition.
-For handling the async functions, we use the “await” keyword while invoking to 
 function to wait for the promise to resolve.
